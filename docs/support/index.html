Product Support

Installation, subscription, and troubleshooting guidance for Toolbox Suite.

Quick help

Install or update

Install Toolbox Suite from its official Microsoft Store listing. Store updates are delivered by Microsoft.

Restore Pro

Sign in to Microsoft Store with the purchasing account, then use Toolbox Suite → Subscription → Restore Purchase.

Manage subscription

Use Toolbox Suite → Subscription → Manage Subscription, or Microsoft account Services & subscriptions.

Files and output

Confirm that the input exists and choose an output folder where your Windows account has write permission.

Subscription products

  • Toolbox Pro Monthly — Store ID 9P4K5Z77Z30S.
  • Toolbox Pro Annual — Store ID 9P0BJR6OXTQ6.

Purchases, renewals, regional pricing, taxes, cancellations, and refunds are handled by Microsoft Store. Toolbox Suite does not process payment-card details directly.

If Pro is not active

  1. Verify that Windows and Microsoft Store use the account that purchased the subscription.
  2. Check that the subscription is active in Microsoft account Services & subscriptions.
  3. Restart Microsoft Store, then restart Toolbox Suite.
  4. Use Restore Purchase in Toolbox Suite.

Application troubleshooting

  • Install pending Windows and Microsoft Store updates.
  • Retry with a local file and a writable local output folder.
  • Keep an original backup before large batch operations.
  • Use Windows Settings → Apps → Toolbox Suite → Advanced options → Repair if the app cannot start.
