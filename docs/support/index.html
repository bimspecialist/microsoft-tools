Toolbox Suite quick checksفحوصات سريعة لـToolbox Suite

  • Install pending Windows and Microsoft Store updates.ثبّت تحديثات Windows وMicrosoft Store المعلّقة.
  • For Pro access, sign in with the purchasing Microsoft Store account and use Subscription → Restore Purchase.لاستعادة Pro، سجّل الدخول بحساب Microsoft Store المستخدم في الشراء ثم اختر الاشتراك ← استعادة الشراء.
  • For file-operation issues, retry with a local source and a writable local output folder.لمشكلات معالجة الملفات، أعد المحاولة باستخدام ملف مصدر محلي ومجلد إخراج محلي قابل للكتابة.
  • If the app cannot start, use Windows Settings → Apps → Toolbox Suite → Advanced options → Repair.إذا تعذر تشغيل التطبيق، استخدم إعدادات Windows ← التطبيقات ← Toolbox Suite ← الخيارات المتقدمة ← إصلاح.

Contact supportالتواصل مع الدعم

Include the product name, Windows version, a clear description of the issue, and any safe error text or screenshot that helps reproduce it. Do not send passwords, authentication tokens, or payment-card information.اذكر اسم المنتج وإصدار Windows ووصفًا واضحًا للمشكلة، وأرفق نص الخطأ أو لقطة شاشة آمنة إذا كانت تساعد على إعادة المشكلة. لا ترسل كلمات المرور أو رموز المصادقة أو بيانات بطاقات الدفع.
