Product Supportدعم Toolbox Suite

Installation, subscription, and troubleshooting guidance for Toolbox Suite.إرشادات التثبيت وإدارة الاشتراك وحل المشكلات في Toolbox Suite.

Quick helpمساعدة سريعة

Install or updateالتثبيت أو التحديث

Install Toolbox Suite from its official Microsoft Store listing. Store updates are delivered by Microsoft.ثبّت Toolbox Suite من صفحته الرسمية في Microsoft Store. وتصل تحديثات التطبيق عبر Microsoft Store.

Restore Proاستعادة Pro

Sign in to Microsoft Store with the purchasing account, then use Toolbox Suite → Subscription → Restore Purchase.سجّل الدخول إلى Microsoft Store بالحساب المستخدم في الشراء، ثم افتح Toolbox Suite واختر: الاشتراك ← استعادة الشراء.

Manage subscriptionإدارة الاشتراك

Use Toolbox Suite → Subscription → Manage Subscription, or Microsoft account Services & subscriptions.من داخل Toolbox Suite اختر: الاشتراك ← إدارة الاشتراك، أو استخدم قسم الخدمات والاشتراكات في حساب Microsoft.

Files and outputالملفات ومجلد الإخراج

Confirm that the input exists and choose an output folder where your Windows account has write permission.تأكد من وجود ملف المصدر، واختر مجلد إخراج محليًا يملك حساب Windows صلاحية الكتابة فيه.

Subscription productsخيارات الاشتراك

  • Toolbox Pro Monthly — Store ID 9P4K5Z77Z30S.
  • Toolbox Pro Annual — Store ID 9P0BJR6OXTQ6.

Purchases, renewals, regional pricing, taxes, cancellations, and refunds are handled by Microsoft Store. Toolbox Suite does not process payment-card details directly.تتولى Microsoft Store عمليات الشراء والتجديد والأسعار المحلية والضرائب والإلغاء والاسترداد. ولا يعالج Toolbox Suite بيانات بطاقات الدفع مباشرة.

If Pro is not activeإذا لم يتم تفعيل Pro

  1. Verify that Windows and Microsoft Store use the account that purchased the subscription.تأكد من أن Windows وMicrosoft Store يستخدمان الحساب الذي تم شراء الاشتراك من خلاله.
  2. Check that the subscription is active in Microsoft account Services & subscriptions.تحقق من أن الاشتراك نشط في قسم الخدمات والاشتراكات بحساب Microsoft.
  3. Restart Microsoft Store, then restart Toolbox Suite.أعد تشغيل Microsoft Store، ثم أعد تشغيل Toolbox Suite.
  4. Use Restore Purchase in Toolbox Suite.استخدم خيار استعادة الشراء داخل Toolbox Suite.

Application troubleshootingحل مشكلات التطبيق

  • Install pending Windows and Microsoft Store updates.ثبّت تحديثات Windows وMicrosoft Store المعلّقة.
  • Retry with a local file and a writable local output folder.أعد المحاولة باستخدام ملف محلي ومجلد إخراج محلي قابل للكتابة.
  • Keep an original backup before large batch operations.احتفظ بنسخة احتياطية من الملفات الأصلية قبل تنفيذ عمليات جماعية كبيرة.
  • Use Windows Settings → Apps → Toolbox Suite → Advanced options → Repair if the app cannot start.إذا تعذر تشغيل التطبيق، انتقل إلى إعدادات Windows ← التطبيقات ← Toolbox Suite ← الخيارات المتقدمة ← إصلاح.
