Install and updateالتثبيت والتحديث

  1. Install Toolbox Suite from its official Microsoft Store listing.
  2. Sign in to Microsoft Store with the account used for purchases.
  3. Launch Toolbox Suite after installation completes.
  4. Keep Microsoft Store updates enabled.
  1. ثبّت Toolbox Suite من صفحته الرسمية في Microsoft Store.
  2. سجّل الدخول إلى Microsoft Store بالحساب المستخدم للشراء.
  3. شغّل Toolbox Suite بعد اكتمال التثبيت.
  4. اترك تحديثات Microsoft Store مفعّلة.

Microsoft Store product ID: 9N8MJLGKWWFG.معرّف المنتج في Microsoft Store: 9N8MJLGKWWFG.

Subscription and billingالاشتراك والفوترة

Purchases, renewals, regional pricing, taxes, cancellations, and refunds are handled by Microsoft Store. Toolbox Suite does not process payment-card details directly.تتولى Microsoft Store عمليات الشراء والتجديد والأسعار المحلية والضرائب والإلغاء والاسترداد. ولا يعالج Toolbox Suite بيانات بطاقات الدفع مباشرة.

  • Toolbox Pro Monthly — Store ID 9P4K5Z77Z30S.
  • Toolbox Pro Annual — Store ID 9P0BJR6OXTQ6.

Safe file workflowsمعالجة الملفات بأمان

Keep an original backup before large batch operations. Confirm that the source file exists, is not locked by another application, and that the selected output folder is writable.احتفظ بنسخة احتياطية من الملفات الأصلية قبل العمليات الجماعية الكبيرة. تأكد من وجود ملف المصدر ومن أنه غير مقفل بواسطة تطبيق آخر، وتأكد من إمكانية الكتابة في مجلد الإخراج.

Restore Proاستعادة Pro

Sign in to Microsoft Store with the purchasing account, then use Toolbox Suite → Subscription → Restore Purchase. You can also verify the subscription in Microsoft account Services & subscriptions.سجّل الدخول إلى Microsoft Store بالحساب المستخدم في الشراء، ثم افتح Toolbox Suite واختر: الاشتراك ← استعادة الشراء. ويمكنك أيضًا التحقق من الاشتراك من قسم الخدمات والاشتراكات في حساب Microsoft.

Troubleshootingحل المشكلات

Install pending Windows and Microsoft Store updates, restart Windows, and retry using a local source file and writable local output folder. If the application cannot start, use Windows Settings → Apps → Toolbox Suite → Advanced options → Repair.ثبّت تحديثات Windows وMicrosoft Store المعلّقة، وأعد تشغيل Windows، ثم أعد المحاولة باستخدام ملف مصدر محلي ومجلد إخراج محلي قابل للكتابة. إذا تعذر تشغيل التطبيق، استخدم إعدادات Windows ← التطبيقات ← Toolbox Suite ← الخيارات المتقدمة ← إصلاح.
