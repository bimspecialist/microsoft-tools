Microsoft Tools privacy policy.سياسة خصوصية Microsoft Tools.

Effective August 15, 2026. This policy describes how Microsoft Store applications published by BIM Specialist Software handle information. Product-specific behavior is identified below.سارية من 15 أغسطس 2026. توضح هذه السياسة كيفية تعامل تطبيقات Microsoft Store المنشورة بواسطة BIM Specialist Software مع المعلومات، مع توضيح السلوك الخاص بكل منتج عند الحاجة.

Current product:المنتج الحالي: Toolbox Suite processes selected working files locally on the Windows device and does not upload those working files to BIM Specialist Software servers by default.يعالج ملفات العمل المحددة محليًا على جهاز Windows ولا يرفعها إلى خوادم BIM Specialist Software افتراضيًا.

1. Product information1. معلومات المنتجات

Each Microsoft Tools application may process the files or information required to perform the operation requested by the user. Product documentation identifies material product-specific behavior.قد يعالج كل تطبيق من Microsoft Tools الملفات أو المعلومات اللازمة لتنفيذ العملية التي يطلبها المستخدم. ويوضح دليل كل منتج أي سلوك مهم خاص به.

2. Toolbox Suite local processing2. المعالجة المحلية في Toolbox Suite

Toolbox Suite processes documents and files when the user selects them or requests an operation. Core working-file processing takes place locally on the Windows device.يعالج Toolbox Suite المستندات والملفات عندما يحددها المستخدم أو يطلب تنفيذ عملية عليها. وتتم العمليات الأساسية على ملفات العمل محليًا على جهاز Windows.

3. Local application data3. بيانات التطبيق المحلية

Applications may store settings required for their operation. Toolbox Suite may store language, appearance, recent tools, favorites, output folders, interface settings, and cached Microsoft Store entitlement status in local application data.قد تخزن التطبيقات الإعدادات اللازمة لعملها. وقد يخزن Toolbox Suite محليًا اللغة والمظهر والأدوات الأخيرة والمفضلة ومجلدات الإخراج وإعدادات الواجهة وحالة استحقاق Microsoft Store المؤقتة.

4. Microsoft Store services4. خدمات Microsoft Store

Microsoft Store may provide distribution, purchases, subscriptions, restoration, and license verification. Microsoft processes related account, payment, transaction, device, and licensing information under its own terms and privacy statement. BIM Specialist Software does not receive full payment-card details.قد توفر Microsoft Store خدمات التوزيع والشراء والاشتراكات واستعادة المشتريات والتحقق من الترخيص. وتعالج Microsoft معلومات الحساب والدفع والمعاملات والجهاز والترخيص وفق شروطها وسياسة الخصوصية الخاصة بها. ولا تتلقى BIM Specialist Software بيانات بطاقة الدفع الكاملة.

5. File transmission5. نقل الملفات

Toolbox Suite does not intentionally transmit selected working files to BIM Specialist Software servers. If a future online feature materially changes file handling, the relevant product interface and this policy will be updated before that processing is introduced.لا يرسل Toolbox Suite ملفات العمل المحددة إلى خوادم BIM Specialist Software بشكل مقصود. وإذا أضيفت مستقبلًا ميزة عبر الإنترنت تغيّر طريقة معالجة الملفات بصورة جوهرية، فسيتم تحديث واجهة المنتج ذات الصلة وهذه السياسة قبل تقديم تلك المعالجة.

6. Retention and deletion6. الاحتفاظ بالبيانات وحذفها

Locally stored application preferences remain until changed, reset, cleared, or removed with the application. Microsoft Store transaction and licensing records are controlled by Microsoft.تبقى تفضيلات التطبيق المخزنة محليًا إلى أن يتم تغييرها أو إعادة ضبطها أو مسحها أو إزالة التطبيق. وتتحكم Microsoft في سجلات معاملات Microsoft Store والترخيص.

7. Security and backups7. الأمان والنسخ الاحتياطي

Applications are designed to minimize unnecessary data handling. No software environment can be guaranteed completely secure, and users should keep suitable backups of important files.تُصمم التطبيقات لتقليل معالجة البيانات غير الضرورية. ولا يمكن ضمان الأمان الكامل لأي بيئة برمجية، وينبغي للمستخدمين الاحتفاظ بنسخ احتياطية مناسبة من الملفات المهمة.

8. Changes and contact8. التغييرات والتواصل

This policy may be updated when products or applicable requirements change. For privacy or product questions, use the official Microsoft Tools support center.قد تُحدّث هذه السياسة عند تغير المنتجات أو المتطلبات المعمول بها. لاستفسارات الخصوصية أو المنتجات، استخدم مركز دعم Microsoft Tools الرسمي.
