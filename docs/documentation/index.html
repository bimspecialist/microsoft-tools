Install and updateالتثبيت والتحديث

  1. Install Toolbox Suite from its official Microsoft Store listing.
  2. Sign in to Microsoft Store with the account you intend to use for purchases.
  3. Launch Toolbox Suite after installation completes.
  4. Keep Microsoft Store updates enabled so supported updates can be delivered.
  1. ثبّت Toolbox Suite من صفحته الرسمية في Microsoft Store.
  2. سجّل الدخول إلى Microsoft Store بالحساب الذي ستستخدمه للشراء وإدارة الاشتراك.
  3. شغّل Toolbox Suite بعد اكتمال التثبيت.
  4. اترك تحديثات Microsoft Store مفعّلة للحصول على الإصدارات المدعومة عند توفرها.

Official Microsoft Store product ID: 9N8MJLGKWWFG.معرّف المنتج الرسمي في Microsoft Store: 9N8MJLGKWWFG.

Subscription and billingالاشتراك والفوترة

Purchases, renewals, regional pricing, taxes, cancellations, and refunds are handled by Microsoft Store. Toolbox Suite does not process payment-card details directly.تتولى Microsoft Store عمليات الشراء والتجديد والأسعار المحلية والضرائب والإلغاء والاسترداد. ولا يعالج Toolbox Suite بيانات بطاقات الدفع مباشرة.

  • Toolbox Pro Monthly — Store ID 9P4K5Z77Z30S.
  • Toolbox Pro Annual — Store ID 9P0BJR6OXTQ6.

Safe file workflowsمعالجة الملفات بأمان

Toolbox Suite is intended for practical PDF, image, file, and document workflows. Before large or destructive batch operations, keep an original backup and confirm the output folder is writable.صُمم Toolbox Suite لتنفيذ مهام PDF والصور والملفات والمستندات. قبل تشغيل عمليات جماعية كبيرة أو أي عملية قد تغيّر الملفات، احتفظ بنسخة احتياطية من الملفات الأصلية وتأكد من إمكانية الكتابة في مجلد الإخراج.

  1. Confirm the source file exists and is not locked by another application.
  2. Select a local output folder with write permission.
  3. Run a small test operation first when processing many files.
  4. Review the generated output before replacing any original files.
  1. تأكد من وجود ملف المصدر ومن أنه غير مستخدم أو مقفل بواسطة تطبيق آخر.
  2. اختر مجلد إخراج محليًا لديك صلاحية الكتابة فيه.
  3. عند معالجة عدد كبير من الملفات، ابدأ باختبار العملية على عدد محدود منها.
  4. راجع الملفات الناتجة قبل استبدال أي ملفات أصلية.

Restore Proاستعادة Pro

If Pro is not active after a reinstall or device change, sign in to Microsoft Store with the purchasing account, then use Toolbox Suite → Subscription → Restore Purchase.إذا لم يتم تفعيل Pro بعد إعادة تثبيت التطبيق أو تغيير الجهاز، سجّل الدخول إلى Microsoft Store بالحساب المستخدم في الشراء، ثم افتح Toolbox Suite واختر: الاشتراك ← استعادة الشراء.

You can also verify the subscription in Microsoft account Services & subscriptions.يمكنك أيضًا التحقق من حالة الاشتراك من قسم الخدمات والاشتراكات في حساب Microsoft.

Troubleshootingحل المشكلات

The application does not startالتطبيق لا يبدأ التشغيل

Install pending Windows and Microsoft Store updates, restart Windows, then try Windows Settings → Apps → Toolbox Suite → Advanced options → Repair.ثبّت تحديثات Windows وMicrosoft Store المعلّقة، ثم أعد تشغيل Windows. إذا استمرت المشكلة، انتقل إلى إعدادات Windows ← التطبيقات ← Toolbox Suite ← الخيارات المتقدمة ← إصلاح.

A file operation failsفشل تنفيذ عملية على أحد الملفات

Retry with a local source file and a local writable output folder. Check that the source is valid and not open in another application.أعد المحاولة باستخدام ملف مصدر محلي ومجلد إخراج محلي قابل للكتابة. وتأكد من سلامة ملف المصدر ومن أنه غير مفتوح في تطبيق آخر.
