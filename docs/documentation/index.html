Install and updateالتثبيت والتحديث

  1. Install Toolbox Suite from its official Microsoft Store listing.
  2. Sign in to Microsoft Store with the account you intend to use for purchases.
  3. Launch Toolbox Suite after installation completes.
  4. Keep Microsoft Store updates enabled so supported updates can be delivered.
  1. ثبّت Toolbox Suite من صفحته الرسمية في Microsoft Store.
  2. سجّل الدخول إلى Microsoft Store بالحساب الذي ستستخدمه للشراء.
  3. شغّل Toolbox Suite بعد اكتمال التثبيت.
  4. أبقِ تحديثات Microsoft Store مفعلة لاستلام التحديثات المدعومة.

Official Microsoft Store product ID: 9N8MJLGKWWFG.معرّف المنتج الرسمي في Microsoft Store: 9N8MJLGKWWFG.

Subscription and billingالاشتراك والفوترة

Purchases, renewals, regional pricing, taxes, cancellations, and refunds are handled by Microsoft Store. Toolbox Suite does not process payment-card details directly.تتم عمليات الشراء والتجديد والأسعار الإقليمية والضرائب والإلغاء والاسترداد عبر Microsoft Store. لا يعالج Toolbox Suite بيانات بطاقات الدفع مباشرة.

  • Toolbox Pro Monthly — Store ID 9P4K5Z77Z30S.
  • Toolbox Pro Annual — Store ID 9P0BJR6OXTQ6.

Safe file workflowsسير عمل آمن للملفات

Toolbox Suite is intended for practical PDF, image, file, and document workflows. Before large or destructive batch operations, keep an original backup and confirm the output folder is writable.تم تصميم Toolbox Suite لمهام PDF والصور والملفات والمستندات. قبل العمليات الكبيرة أو التي قد تغيّر الملفات، احتفظ بنسخة أصلية وتأكد من أن مجلد الإخراج قابل للكتابة.

  1. Confirm the source file exists and is not locked by another application.
  2. Select a local output folder with write permission.
  3. Run a small test operation first when processing many files.
  4. Review the generated output before replacing any original files.
  1. تأكد من وجود الملف الأصلي وأنه غير مقفل بواسطة تطبيق آخر.
  2. اختر مجلد إخراج محليًا لديك صلاحية الكتابة فيه.
  3. نفّذ عملية اختبار صغيرة أولًا عند معالجة عدد كبير من الملفات.
  4. راجع النتائج قبل استبدال أي ملفات أصلية.

Restore Proاستعادة Pro

If Pro is not active after a reinstall or device change, sign in to Microsoft Store with the purchasing account, then use Toolbox Suite → Subscription → Restore Purchase.إذا لم يتم تفعيل Pro بعد إعادة التثبيت أو تغيير الجهاز، سجّل الدخول إلى Microsoft Store بالحساب المستخدم في الشراء، ثم استخدم Toolbox Suite ← الاشتراك ← استعادة الشراء.

You can also verify the subscription in Microsoft account Services & subscriptions.يمكنك أيضًا التحقق من حالة الاشتراك من صفحة الخدمات والاشتراكات في حساب Microsoft.

Troubleshootingاستكشاف الأخطاء

The application does not startالتطبيق لا يعمل

Install pending Windows and Microsoft Store updates, restart Windows, then try Windows Settings → Apps → Toolbox Suite → Advanced options → Repair.ثبّت تحديثات Windows وMicrosoft Store المعلقة، وأعد تشغيل Windows، ثم جرّب إعدادات Windows ← التطبيقات ← Toolbox Suite ← الخيارات المتقدمة ← إصلاح.

A file operation failsفشل تنفيذ عملية على ملف

Retry with a local source file and a local writable output folder. Check that the source is valid and not open in another application.أعد المحاولة بملف مصدر محلي ومجلد إخراج محلي قابل للكتابة. تحقق من صحة الملف وأنه غير مفتوح في تطبيق آخر.
