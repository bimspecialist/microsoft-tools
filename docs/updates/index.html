Updates are delivered through Microsoft Store.تصل تحديثات التطبيق عبر Microsoft Store.

Open Microsoft Storeافتح Microsoft StoreUse the same Windows environment where the app is installed.استخدم الجهاز نفسه الذي تم تثبيت Toolbox Suite عليه.

3
Install and reopen Toolbox Suiteثبّت التحديث ثم أعد فتح Toolbox SuiteIf an update is available, finish installation before reopening the app.إذا توفر تحديث، أكمل تثبيته قبل إعادة تشغيل التطبيق.
